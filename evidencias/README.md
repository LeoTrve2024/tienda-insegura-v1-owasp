# Evidencias de la Versión 1

Esta carpeta se entrega como estructura para colocar las pruebas generadas en
el equipo del estudiante.

## Carpetas

- `capturas/`: imágenes PNG o JPG.
- `sqlmap-output/`: salida de los scripts de sqlmap.
- `reportes/`: Dependency-Check u otros reportes.

No se incluyen imágenes inventadas ni resultados de una máquina distinta.
